# Rittick SDK workspace

Initial repository and npm workspace scaffold for UI-001. `@rittick/ui` is a placeholder package and is **not** yet built or publishable. `@rittick/auth` will be added in its scheduled story.

## Bootstrap

```bash
npm ci
npm run check:workspace
```

Node 22 or 24 is required. TypeScript, build/exports, linting, testing and Storybook are scheduled for UI-002 through UI-006. No package is ready to publish.

See `ARCHITECTURE.md`, `PROGRESS.md`, `DEVELOPMENT_PROGRESS.md`, and `docs/adr/`.
